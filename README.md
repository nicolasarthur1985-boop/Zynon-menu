# Zyon Panel — Android

Menu flutuante demonstrativo em Kotlin. Compatível com Android 8.0+.

## Compilar
1. Abra a pasta `ZyonPanel` no Android Studio.
2. Aguarde a sincronização do Gradle.
3. Use **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. O APK será gerado em `app/build/outputs/apk/debug/app-debug.apk`.

## Executar
1. Instale o APK.
2. Abra Zyon Panel.
3. Toque em **ATIVAR MENU FLUTUANTE**.
4. Conceda a permissão de sobreposição.
5. Volte ao app e toque novamente no botão.

As opções ESP são preferências e controles de interface demonstrativos. O projeto não lê memória do Blood Strike, não identifica jogadores e não automatiza a mira.
